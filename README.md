## 🔧 Команды и права

### Команды

| Команда         | Описание                           | Права       |
|-----------------|------------------------------------|-------------|
| `/spawn`        | Телепорт на спавн                  | Не надо     |
| `/broadcast`    | Вкл/Выкл автосообщения             | Не надо     |
| `/hub`          | Показать помощь                    | `hub.admin` |
| `/hub reload`   | Перезагрузить конфигурацию         | `hub.admin` |
| `/hub setspawn` | Принудительно войти в боевой режим | `hub.admin` |
| `/hub items`    | Управление предметами игрока       | `hub.admin`  |

### Права доступа

| Право       | Описание |
|-------------|----------|
| `hub.admin` | Доступ ко всем командам плагина |
